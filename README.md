# 🔐 Password Generator Pro (Secure-Backup Edition)

Password Generator Pro は、外部サーバーへの通信を一切排除し、ブラウザ上で完結する「完全ローカル・スタンドアロン」の高機能パスワード生成ツールです。[cite: 2]
あなたが記憶している「秘密のフレーズ」から、強力で一意なパスワードを数学的（決定論的）に計算して出力します。また、生成したパスワードを復号鍵として利用する「暗号化メモ機能」も備えています。[cite: 2]

## ✨ 主な機能と特徴

### 1. 強力なパスワード自動生成[cite: 2]
* **決定論的生成:** 「文１」と「文２」の組み合わせから、常に同じパスワードを復元・生成します。[cite: 2] パスワード自体を保存する必要がなく、フレーズを覚えておくだけで済みます。[cite: 2]
* **第3の鍵（アクセスキー）:** さらなるセキュリティ向上のため、任意のアクセスキーを追加可能です。[cite: 2]
* **柔軟な設定:** パスワード長は16〜256文字までスライダーで調整可能。[cite: 2] 記号の有無もワンクリックで切り替えられます。[cite: 2]
* **自動クリアタイマー:** セキュリティ保護のため、パスワード生成から60秒経過すると画面とクリップボードを自動消去します。[cite: 2]

### 2. 暗号化メモとファイル添付（IndexedDB）[cite: 2]
* **ゼロ知識暗号化メモ:** 生成されたパスワードをマスターキーとして、サイト名やアカウント情報などのメモを暗号化保存できます。[cite: 2]
* **ファイル添付対応:** 画像、PDF、テキストなどのファイルを1ファイル最大10MB、合計30MBまでメモに添付して暗号化保存できます。[cite: 2] アプリ内で直接ファイルの中身を確認できるプレビュー機能も搭載しています。[cite: 2]
* **キーの匿名化:** データ保存時のキー（名前）は HMAC-SHA-256 で二重にハッシュ化されるため、ストレージを覗き見られても元のフレーズを推測することは不可能です。[cite: 2]

### 3. セキュアなバックアップ＆リストア[cite: 2]
* **二重暗号化バックアップ:** 全てのデータ（メモ履歴、暗号化ファイル、設定）をひとつのJSONファイルに書き出せます。[cite: 2] 書き出し時には専用の「バックアップパスワード」による全体の再暗号化（AES-GCM）が行われます。[cite: 2]

## 🛡️ セキュリティ設計とアルゴリズム[cite: 2]

本アプリケーションは Web Crypto API をフル活用し、以下の技術で構築されています。[cite: 2]

* **総当たり攻撃対策:** パスワード生成のシード作成時やメモの暗号化時に、**PBKDF2** アルゴリズムによるストレッチング（5万回〜30万回の反復計算）を実施し、解析を物理的に困難にしています。[cite: 2]
* **均等なランダム性:** パスワード生成ロジックにおいて暗号学的な偏りを排除する「Rejection Sampling」を採用しています。[cite: 2]
* **ペイロード保護:** メモ本文および添付ファイルは **AES-GCM (256bit)** により一括暗号化され、改ざん検知と高い機密性を両立しています。[cite: 2]

## 🚀 使い方

インストールは不要です。

1. 本リポジトリのHTMLファイルをダウンロード、またはGitHub Pagesで開きます。
2. 「文１」と「文２」にあなただけの秘密のフレーズを入力します。[cite: 2]
3. 自動生成されたパスワードをコピーして利用します。[cite: 2]
4. 必要に応じて「メモ」ボタンを押し、パスワードに紐づくアカウント情報やファイルを保存します。[cite: 2]

## ⚠️ 重要な注意事項

* **自己責任での管理:** 「文１」「文２」（およびアクセスキー）を忘れると、保存したメモや添付ファイルは**絶対に復元できません**。[cite: 2]
* **データ消失のリスク:** 保存されたデータはブラウザ内部（IndexedDB）に存在します。[cite: 2] ブラウザのキャッシュクリアを行うとデータが消去されるため、定期的な一括バックアップ（書き出し）を強く推奨します。[cite: 2]
